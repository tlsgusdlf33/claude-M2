# 카카오 / 구글 로그인 연동 준비

현재 두 로그인은 테스트 모드(실제 인증 없음)입니다. 실제 연동에는 **본인 계정으로만 발급할 수 있는 키**가 필요합니다.

## 앱 정보 (등록할 때 입력)
| 항목 | 값 |
|---|---|
| 패키지 이름 | `com.moonlight.greenhouse` |
| 서명 SHA-1 (구글) | `FC:49:5C:D1:2B:44:B6:6D:13:25:4B:08:B1:6F:80:86:1D:BE:53:22` |
| 서명 SHA-256 | `2D:04:E6:F7:BA:B6:85:08:17:85:12:B7:61:D4:A6:06:06:0A:D4:EA:2A:D4:07:33:40:EE:9E:E7:56:BD:18:AA` |
| 키 해시 (카카오) | `/Elc0StEtm0TJUsIsW+Ahh2+UyI=` |

이 값은 현재 테스트용 서명 키(`android-app/debug.keystore`) 기준입니다. 구글 플레이 출시용 키를 새로 만들면 **SHA-1과 키 해시를 다시 등록**해야 합니다 (플레이 앱 서명을 쓰면 플레이 콘솔의 앱 서명 키 값도 추가).

## 구글
1. Google Cloud Console에서 프로젝트 생성, OAuth 동의 화면 설정
2. 사용자 인증 정보 → OAuth 클라이언트 ID 만들기
   - 유형 **Android**: 위 패키지 이름 + SHA-1
   - 유형 **웹 애플리케이션**: 앱이 토큰을 받을 때 쓰는 ID
3. 필요한 값: **웹 클라이언트 ID** (`xxxx.apps.googleusercontent.com`)

## 카카오
1. Kakao Developers에서 앱 생성
2. 플랫폼 → Android: 패키지 이름 + 키 해시 등록
3. 제품 설정 → 카카오 로그인 활성화 (동의항목은 닉네임 정도만 권장)
4. 필요한 값: **네이티브 앱 키**

## 연동 후 구조
- 앱은 로그인 성공 시 받은 사용자 고유 ID로 계정(`kakao-ID`, `google-ID`)을 만들어 지금과 같은 방식으로 진행 데이터를 저장합니다.
- 데이터는 아직 폰에 저장됩니다. 같은 카카오/구글 계정으로 폰을 바꿔도 이어지게 하려면 서버 저장(예: Firebase)이 추가로 필요합니다.
- 앱 껍데기(네이티브 로그인 플러그인)가 바뀌므로 APK를 다시 설치해야 합니다.
