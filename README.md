# Claude-M

안드로이드용 강아지 하이브리드(자동 + 직접 조작) 스테이지 클리어 RPG 구상 저장소입니다.

| 경로 | 내용 |
|---|---|
| `docs/DESIGN.md` | 기획서 (전투 화면, 성장 구조, 스테이지 1~10, 보스, 수익화) |
| `prototype/index.html` | 브라우저에서 열어 바로 해볼 수 있는 단일 파일 프로토타입 |
| `tools/sim.js` | 전투 로직을 화면 없이 돌려 밸런스를 확인하는 스크립트 |
| `tools/shell.html`, `tools/updater.js`, `tools/make-www.py` | 앱 시작 화면, 자동 업데이트 코드, 앱용 파일 생성기 |
| `godot/` | Godot 4 이식본 (전투 로직 + 최소 화면, **미검증**) |

## 실행

- 프로토타입: `prototype/index.html`을 브라우저(모바일 권장)에서 엽니다.
- 밸런스 시뮬레이션: `node tools/sim.js prototype/index.html`

## 조작

- 손을 떼면 자동 전투
- 화면을 누르고 좌우로 끌면 직접 조작 (공격력 +30%, 필살기 충전 가속)
- 필살기 게이지가 차면 하단 버튼을 탭

## Godot 프로젝트

`godot/` 폴더를 Godot 4.3 이상에서 열면 됩니다. 전투 로직은 `godot/scripts/game_core.gd`, 화면은 `main.gd`입니다. 메뉴, 강화, 저장은 아직 없고 이모지 대신 도형으로 그립니다. 작성자는 Godot를 실행해 확인하지 못했으므로 열었을 때 오류가 나면 알려주세요.

## APK로 폰에 설치하기

처음 한 번만 설치하면 됩니다. 이후 게임 화면과 규칙을 고친 내용은 앱이 알아서 받아 갑니다 (아래 "자동 업데이트").

1. 폰 브라우저에서 이 저장소의 Releases 페이지를 엽니다 (저장소가 공개라 로그인 없이 받을 수 있습니다).
2. 가장 최근 릴리스의 `mmyg-debug.apk`를 내려받아 엽니다.
3. "출처를 알 수 없는 앱 설치"를 허용하라는 안내가 뜨면 해당 브라우저에 허용합니다.

APK는 `android-app/`, `tools/shell.html`, `build-apk.yml`이 바뀔 때만 새로 만들어집니다. 직접 만들려면 Actions 탭의 "Build APK"에서 Run workflow를 누르세요. 고정 서명 키(`android-app/debug.keystore`)로 서명하므로 이후 APK는 지우지 않고 덮어 설치됩니다. 빌드가 이 키를 쓰지 않았으면 실패하도록 검사합니다.

**APK #2, #3은 빌드마다 다른 임시 키로 서명되어 있어서** 그 위에는 덮어 설치할 수 없습니다. 이미 설치했다면 앱을 한 번 삭제하고(저장 데이터도 지워집니다) 이후 버전을 설치하세요.

`debug.keystore`는 암호가 공개된 테스트용 키입니다. 구글 플레이 출시용은 별도 키로 새로 만들어야 합니다.

## 자동 업데이트

`prototype/`를 고쳐 `main`에 올리면 Actions의 "Publish game update"(`ota.yml`)가 새 게임 파일을 `gh-pages` 브랜치에 올립니다. 설치된 앱은 켜질 때(그리고 앱으로 돌아올 때) 이를 확인해서 받고, 메뉴의 "지금 적용"이나 다음 실행 때 바뀝니다. 진행 데이터는 유지됩니다.

- **저장소가 공개여야 앱이 업데이트를 받을 수 있습니다.** 비공개이면 앱은 서버에 연결하지 못하고 기존 버전 그대로 동작합니다.
- 앱 껍데기(광고, 결제 플러그인, 권한, 시작 화면)를 바꾼 경우는 APK를 다시 설치해야 합니다.
- 새 버전이 시작하자마자 고장 나면 다음 실행에서 앱에 들어 있는 버전으로 돌아갑니다.
- 앱 구조: `tools/shell.html`(고정된 시작 화면) + `game.txt`(게임 본체). `tools/make-www.py`가 두 파일과 업데이트용 `game.html`, `version.json`을 만듭니다.
